Swap

Instantly swap USDC ↔ EURC on the same network, or perform a cross-chain swap with CCTP routing in a single transaction. Liquidity Provider Fee: 0.30%.

Swap Types#

Same-Chain Swap

Swap USDC ↔ EURC on the same network in a single on-chain transaction. Instant settlement, no bridging required.

Cross-Chain Swap

Swap and bridge in one step using CCTP routing. For example: USDC on Ethereum → EURC on ARC Network in a single transaction.
